Libro Documentation

The complete administrator guide to the Libro Integrated Library Management System. This documentation covers every feature, workflow, and configuration option available to library administrators.

Version 1.0.0 Last Updated: March 12, 2026 Administrator Guide

When you launch Libro for the first time, the application will attempt to verify your license. If no valid license is found, you will be presented with the Activation screen.

🖼️
Screenshot: Activation Page

Grace Period

If your license expires, Libro enters a 7-day grace period. During this time, all features remain functional, but a warning dialog will appear on each login showing the remaining grace days. After the grace period ends, the application will be blocked until the license is renewed.

⚠️
License Blocked If your license is blocked, you will see a screen displaying your organization details, license status, and expiry date. Click "Renew License" to visit the renewal page, or contact support for assistance.

💡
Barcode Auto-Generation The barcode is automatically generated using this pattern: the first two uppercase characters of the Subject field (or "BK" if empty) + the current date in YYMMDD format + a 4-digit random number. For example, if the subject is "Mathematics" and today is March 12, 2026, a generated barcode might be MA2603125847.

ℹ️
Barcode Auto-Generation You do not need to include a barcode column. Libro automatically generates a unique barcode for each imported book using the subject prefix and timestamp pattern. A barcode image (Code128 format) is also saved to the output folder.
⚠️
Quoted Fields The CSV parser handles quoted fields correctly. If a field contains commas, enclose it in double quotes. For example: "Cormen, Thomas H.". To include a literal double-quote inside a quoted field, use two consecutive double-quotes: "A ""Special"" Edition".

Archive & Delete Books

From the Inventory Tracking tool, you have three actions for removing books from active use:

Archive a Book

Archiving removes a book from the active catalog without deleting it. You can restore it later using Unarchive Book. Enter the book's call number when prompted and confirm the action.

Unarchive a Book

Restores a previously archived book back to the active catalog. Enter the book's call number when prompted.

Delete a Book

Permanently removes a book from the database. This action cannot be undone. Enter the book's call number when prompted and confirm.

🚨
Irreversible Action Deleting a book permanently removes it from the database. Consider archiving instead if you may need to restore it later. Always ensure you have a recent backup before performing bulk deletions.

Issue a Book

There are two ways to issue a book to a user:

Method 1 — Quick Checkout (Dashboard)

1
Open "Check Out a Book" Card
On the Quick Tools dashboard, click the Check out a book card.
2
Enter User Number
Type the user's identification number (Admission No, Staff No, or User No). The system will look up and display the user's name for verification.
3
Enter Book Number / Book ID
Type the book's call number or book ID.
4
Click "Issue"
The system validates the request (checks book availability and user's borrowing limit) and issues the book. The due date is calculated based on the user's role-specific loan period.

Method 2 — Issue Book Screen

Navigate to Issue Book from the left sidebar. This opens the full search interface where you can browse available books, search by title or author, and issue them to users.

ℹ️
Borrowing Validation The system automatically checks whether:
  • The book is available (not already checked out)
  • The user has not exceeded their maximum allowed books
  • The due date is calculated based on the user's role-specific loan period (default: 14 days for students, 30 days for staff, 7 days for other users)

  • Number of days overdue
  • Fine amount (calculated as days × fine rate per day)

You can choose to either Pay Fine or Waive Fine.

4
Enter User ID

Troubleshooting

▶ License activation fails
  • Ensure your device is connected to the internet — license validation requires network access.
  • Double-check your Organization ID and License Key for typos.
  • Ensure your license has not expired. Contact support if unsure.
  • Network timeout is 30 seconds. If your connection is slow, try again.
▶ CSV import reports many failures
  • Verify that your CSV has the correct number of columns (12 for books, 8 for users).
  • Ensure required fields are not empty.
  • For book imports, the Value column must be a valid integer.
  • For user imports, enrollment/start year must be greater than 1900, and age must be 1–120.
  • Ensure the header row matches the expected format for the user type you selected.
  • Check for encoding issues — use UTF-8 encoding for your CSV files.
  • For book CSVs, if a field contains commas, enclose it in double quotes.
▶ Emails are not being sent
  • Verify email notifications are enabled in Settings → Email.
  • Check your SMTP configuration — server, port, username, and password.
  • Use the Test Email feature to diagnose SMTP issues.
  • For Gmail: ensure you are using an App Password if 2-Step Verification is enabled.
  • Ensure TLS is enabled (port 587) or SSL (port 465) as appropriate for your provider.
  • Check the Activity Logs (category: EMAIL) for error details.
  • Ensure users have valid email addresses in their profiles.
▶ Barcode scanner not working
  • Ensure your device has a camera and it is not being used by another application.
  • Grant camera permissions to Libro if prompted.
  • Ensure adequate lighting — barcodes are difficult to scan in low light.
  • Hold the barcode steady within the camera viewfinder.
  • Try adjusting the distance between the camera and the barcode.
▶ Backup or restore fails
  • Check that you have sufficient disk space (use the Storage Manager to verify).
  • Ensure the backup destination folder exists and is writable.
  • For cloud backups, verify your internet connection and provider credentials.
  • If restoring, ensure the backup file is not corrupted — check the file size against the backup history.
  • Try using the Test Backup feature before creating an actual backup.
▶ OPAC sync is failing
  • Use Test Connection to verify connectivity to the OPAC server.
  • Check that the API Key is correct and has not expired.
  • Verify the OPAC Server URL is correct and accessible from this machine.
  • Network timeout is 30 seconds — try again if the connection is slow.
  • The system retries up to 3 times with batches of 500 records.
  • Check the Sync History for detailed error messages.
▶ Storage usage is high
  • Open the Storage Manager to view current storage breakdown.
  • Reduce log retention period in Settings → System (default is 90 days).
  • Clean up old backup records in the Backup History.
  • Archive rarely-used books instead of keeping them active.
  • Consider clearing the barcode output folder if you have generated many barcode images.

Frequently Asked Questions

How do non-admin users log in?
Non-admin users (Students, Staff, Other Users) log in using their full name or email as the username and their identification number (Admission No, Staff No, or User No) as the password. They select their appropriate role on the login screen.
Can I have multiple admin accounts?
Yes. Additional admins can be created from the App Manager → Administrators section. Only existing staff members can be promoted to admin. The first admin created during setup is the Super Admin.
What happens when a user's loan period expires?
The book is marked as overdue in the system. Fines accrue daily at the configured rate (default: 10 KES/day) up to the maximum fine cap (default: 500 KES). When the book is returned, the admin is prompted to collect or waive the fine.
Can I change the currency from KES?
Yes. Go to Settings → Circulation → Fine Settings and change the Currency Symbol field to your preferred currency code.
How are barcodes generated?
Barcodes are auto-generated using the pattern: [2-char subject prefix][YYMMDD date][4-digit random number]. They are created in Code128 format. You can also generate barcodes in bulk by date range from the Barcode Writer tool.
What is OPAC?
OPAC (Online Public Access Catalog) is a system that makes your library catalog accessible online. Users can search for books and place reservations through a web portal, which then syncs with your Libro desktop application.
How does the clearance system work?
Clearance checks whether a user has any outstanding library obligations: unreturned books, unreturned digital materials, lost books with unpaid charges, and unpaid fines. All four checks must pass for clearance to be approved. A clearance receipt can be saved as HTML or image.
Is my data encrypted?
Admin passwords are hashed using SHA-256 with random salt. Database backups can optionally be encrypted. The database itself is stored locally in the application data directory.
What is the grace period?
When your license expires, you have a 7-day grace period during which all features remain available. A warning dialog shows how many days remain. After the grace period, the application is blocked until you renew your license.
Can I use Libro offline?
Libro stores all data locally in an SQLite database, so most features work offline. However, these features require network connectivity: license validation, OPAC synchronization, cloud backups, and sending email notifications.
How do I reset the application to factory defaults?
Go to Settings and click "Reset All to Defaults". This resets all settings to their default values. Note: this does not delete your book or user data — only configuration settings are reset.
What user data can non-admin users see and do?
Non-admin users have limited access. They can: view their profile, see their borrowing history, place book reservations, submit suggestions and feedback, and view their currently borrowed books count. They cannot modify the catalog, manage other users, or access administrative tools.

Glossary

ADM NO
Admission Number — a unique identifier assigned to each student. Used as the student's login password.
Barcode
A machine-readable code (Code128 format) assigned to each book for scanning and identification.
Call Number
A unique identifier assigned to a book within the library's classification system. Used to locate the physical book on the shelf.
Checkout
The process of lending a book to a user. Also referred to as "issuing" a book.
Circulation
The system of lending and returning books. Includes issuing, returning, renewals, and overdue management.
Clearance
The process of verifying that a departing user has returned all library materials and paid all outstanding fines.
CSV
Comma-Separated Values — a plain text file format used for bulk importing books and users into Libro.
Fine Cap
The maximum fine amount that can be charged for an overdue book, regardless of how many days overdue. Default: 500 KES.
Grace Period
A 7-day window after license expiry during which Libro remains fully functional with a warning displayed.
ILMS
Integrated Library Management System — the full name of the Libro application.
ISBN
International Standard Book Number — a unique numeric commercial book identifier.
OPAC
Online Public Access Catalog — a web-based interface allowing users to search the library catalog and place reservations remotely.
SMTP
Simple Mail Transfer Protocol — the standard protocol for sending emails. Required for Libro's email notification features.
Super Admin
The first administrator account created during initial setup. Has the highest privileges and cannot be deactivated by other admins.
Sync
Synchronization between the Libro desktop application and the OPAC server. Can be automatic or manual.
TLS / SSL
Transport Layer Security / Secure Sockets Layer — encryption protocols used to secure email communications.
ZXing
An open-source barcode scanning library used by Libro for reading and generating barcodes.
